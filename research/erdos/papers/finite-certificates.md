Two open Erdos problems ask about sums of a few integers with restricted coefficients. Problem 817 asks for `g_3(n)`, the least `N` such that some `n`-subset of `[1, N]` has its `2^n` subset sums free of non-trivial 3-term progressions; the exact values were known to `n = 6`. Question 2 of problem 124 asks, for bases `3 <= d_1 < ... < d_r` with `sum 1/(d_i - 1) >= 1` and `gcd(d_1, ..., d_r) = 1` and for every level `k >= 1`, whether every large integer is a sum `a_1 + ... + a_r` with each `a_i` zero or a sum of distinct powers `d_i^j`, `j >= k`. This paper computes `g_3(7) = 474`, and answers Question 2 for the bases `3, 4, 7` at `k = 1, 2, 3, 4`, and at `k = 1, ..., 5` for the `51` other base sets of at most six bases in `[3, 47]` with `sum 1/(d_i - 1) = 1`, `gcd = 1`, no two bases powers of one integer and two bases with no prime factor other than `2` and `3`. Both results are finite computations, and in both one analytic lemma closes the computation: it makes the search for problem 817 feasible and the check for problem 124 finite. For problem 817 the search over 7-sets is finite by definition and too large without pruning; a lemma bounding how much weight `3^n` distinct ternary sums can put near their centre, proved by Poisson summation against a nonnegative kernel, prunes it to `342` s on `8` threads. For problem 124 the bases `3, 4, 7` have `sum 1/(d - 1) = 1` exactly, where the surplus behind the known certificate vanishes; an exact identity for the deficit reduces every failure of the certificate's step to a small nonzero value of `|4^b - 3^a|`, which the lower bound of Ellison (1971) on `|2^x - 3^y|` excludes above an explicit height, so each level is one finite check, and the check closes exactly when the level is complete. The identity holds for every base set with `sum 1/(d - 1) = 1` and no two bases powers of one integer, where a failing step brings the next powers of any two bases close together; when two of the bases have no prime factor other than `2` and `3`, their gap is at least the smaller power or a multiple of some `|2^x - 3^y|`, so Ellison's bound, with the exceptional exponents read from his Remark (a), closes the check the same way.

## Problem 817: the concentration cut

A set `A` of `n` positive integers is admissible when its `3^n` ternary sums `sum_(a in A) c_a a`, `c_a` in `{0, 1, 2}`, are distinct. By Proposition 4.1 of Korsky (2026), read at source, this holds exactly when the subset sums `<A> = {sum_(a in A) eps_a a : eps_a in {0, 1}}`, `0` included, hold no non-trivial 3-term progression, so `g_3(n)` is the least `N` such that `[1, N]` holds an admissible `n`-set. Three elementary facts are used. A subset of an admissible set is admissible, since its ternary sums are among those of the set. If `A` is admissible in `[1, N]`, so is `{1} U 3A` in `[1, 3N]`, since a ternary sum `c_0 + 3s` of it determines `c_0` modulo `3` and then `s`; so `g_3(n + 1) <= 3 g_3(n)`, the step of the discussion thread. And a uniform ternary sum has variance `(2/3) sum_(a in A) a^2`, at least the variance `(9^n - 1)/12` of `3^n` distinct integers taken with equal weight, so `sum_(a in A) a^2 >= (9^n - 1)/8`.

Put `M = 3^n` and `phi(u) = (1 + 2 cos u)/3`, the characteristic function of `c - 1` for `c` uniform in `{0, 1, 2}`. For `h > 0` let `g(s) = 1 - (s/h)^2` on `[-h, h]` and `g = 0` elsewhere, and let `w = g * g` be its autocorrelation. Then `w(theta) = h W(|theta|/h)` with

```
W(t) = 16/15 - 4t^2/3 + 2t^3/3 - t^5/30   on [0, 2],   W(t) = 0 for t > 2 ,
```

so `w` is even, nonnegative, supported on `[-2h, 2h]`, decreasing on `[0, 2h]`, and `w(0) = 16h/15`.

**Theorem 2.1 (the concentration cut).** Let `H` be a set of positive integers, `r >= 1`, `X >= r`, `n = |H| + r` and `h = pi/(3X)`. Put `K(theta) = prod_(a in H) phi(theta a)`, `U(theta) = prod_(0 <= j < r) phi(theta (X - j))` and `K^- = max(-K, 0)`. If

```
int_(-2h)^(2h) w(theta) (K(theta) U(theta) - K^-(theta) (1 - U(theta))) d theta  >  2 pi w(0)/3^n ,
```

then no `r` distinct positive integers `<= X` outside `H` complete `H` to an admissible `n`-set. Row: [Erdos](../claims/erdos.md), row 50; witness [Problems 817 and 406](../notes/problems-817-406.md), section Problem 817 at n = 7.

**Proof.** Suppose `L` is a set of `r` distinct positive integers `<= X` outside `H` with `H U L` admissible. Let `Y = sum_(a in H U L) e_a a` with `e` uniform in `{-1, 0, 1}^n`. `Y` is a uniform ternary sum minus `sum_(a in H U L) a`, so it takes `M` distinct integer values, each with probability `1/M`, and `E e^(i theta Y) = K(theta) V(theta)` with `V(theta) = prod_(l in L) phi(theta l)`. Let `psi(y) = (1/2pi) int w(theta) e^(i theta y) d theta`. Since `w = g * g` and `g` is even, `psi(y) = (1/2pi) ghat(y)^2 >= 0` with `ghat(y) = int g(s) e^(isy) ds` real, and `ghat(y) = O(y^(-2))`, so `psi` is summable. Poisson summation gives `sum_(y in Z) psi(y) = sum_(k in Z) w(2 pi k) = w(0)`, since the support `[-2h, 2h]` lies inside `(-2pi, 2pi)` when `h <= pi/3`. As `psi >= 0` and the values of `Y` are distinct integers, `E psi(Y) <= (1/M) sum_(y in Z) psi(y) = w(0)/M`. On the other hand `E psi(Y) = (1/2pi) int w K V`. On `|theta| <= 2h = 2pi/(3X)` every `theta l`, `l <= X`, has `|theta l| <= 2pi/3`, where `phi` is nonnegative and decreasing in `|u|`. List `L` as `l_1 > ... > l_r`; then `l_(j+1) <= X - j`, so `phi(theta l_(j+1)) >= phi(theta (X - j)) >= 0` and `U <= V <= 1`. Hence `K V >= K U - K^- (1 - U)`: where `K >= 0` this is `K V >= K U`, and where `K < 0` it is `K V >= K = K U - K^- (1 - U)`. With `w >= 0`, the hypothesis gives `E psi(Y) > w(0)/M`, a contradiction. □

The search behind Fact 1.1 fixes the largest element `N` and picks the others from the top down, holding `D(H) = {sum_(a in H) d_a a : d_a in {-2, ..., 2}}` as one signed bit array. An integer `a` outside an admissible `H` extends it to an admissible set exactly when `a` and `2a` lie outside `D(H)`, since two ternary sums of `H U {a}` agree exactly when `(c - c') a` lies in `D(H)` for two coefficients `c != c'` of `a`, and `D(H)` is symmetric. At a node with chosen set `H`, least chosen element `m` and `r` elements owed, the owed elements lie below `m` and the largest of them, `a`, satisfies three tests: `a >= g_3(r)`, since the owed elements form an admissible `r`-set in `[1, a]`; `sum_(b in H) b^2 + a^2 + (a - 1)^2 + ... + (a - r + 1)^2 >= (9^n - 1)/8`, the variance bound with the owed elements below `a` at their largest; and, when `r >= 3`, `a > X` for the `X < m` that a binary search certifies through Theorem 2.1, since owed elements all `<= X` would complete `H`. The values `g_3(r)`, `r <= 6`, are those of Fact 2.2, computed by the search without the cut; no bound from the literature enters.

Theorem 2.1 is applied in floating point, and only one way: a node is cut when a lower bound for the left side exceeds the right side. By evenness the left side is twice the integral over `[0, 2h]`, where `w` is the polynomial `h W(theta/h)` and the integrand is smooth. The generator evaluates `int_0^(2h) w K U` by composite Simpson on an even number of cells, at least `64` and at least `4hB`, of width `delta`, where `B` is the sum of the elements of `H` and of `X, X - 1, ..., X - r + 1`, and subtracts the Simpson remainder `2h delta^4 max |f''''|/180`, `f = w K U`. Every `m`-th derivative of a product of factors `phi(theta b)` is at most `(sum b)^m` in absolute value, since the `m`-th derivative of `phi(theta b)` is at most `b^m`, and `max |w^(j)| = h^(1 - j) max |W^(j)|` with `max |W^(j)| = 16/15, 0.9283, 8/3, 4, 8` on `[0, 2]` for `j = 0..4`; so

```
|f''''| <= 1.07 h B^4 + 4 B^3 + 16.02 B^2/h + 16 B/h^2 + 8/h^3 .
```

It bounds `int_0^(2h) w K^- (1 - U)` above cell by cell, on the cells where some factor of `K` falls below `10^-12` at an end: by the cell width times `w` at the left end, times the product over `a` in `H` of the larger of `|phi(theta a)|` at the two ends, or `1` where `sin(theta a)` changes sign on the cell, times `1 - U` at the right end. These are upper bounds because `w` decreases and `1 - U` increases on `[0, 2h]`, and `phi(theta a)` is monotone on a cell where `sin(theta a)` keeps its sign, the cell being shorter than `1/(2a)`. On the other cells every factor of `K` is positive at both ends, and a factor `phi(theta a)` negative inside would need a cell of length at least `2pi/(3a)`, so `K^- = 0` there. The node is cut only when the lower bound exceeds `2 pi w(0)/3^n` by a relative margin `10^-9`; the remainder bounds the quadrature error, and the margin, not an interval arithmetic, stands for the rounding.

## Problem 124 at sigma = 1

For `d >= 3` and `k >= 1` let `P(d, k)` be the set of sums of distinct powers `d^j`, `j >= k`, the empty sum `0` included. For a base set `D = {d_1 < ... < d_r}` of integers `>= 3`, `M_k(D)` is the multiset of the powers `d^j`, `d` in `D`, `j >= k`, one copy per base, so `P(d_1, k) + ... + P(d_r, k)` is the set of sums of distinct terms of `M_k(D)`; `M_k(D)` is complete when that set contains every large integer, and `F(D, k)` is then the largest integer outside it. Question 2 of problem 124 asks whether `M_k(D)` is complete at every `k >= 1` when `sigma(D) = sum_(d in D) 1/(d - 1) >= 1` and `gcd(D) = 1`. Put `C_k(D) = sum_(d in D) d^k/(d - 1)`. Sort `M_k(D)` as `a_1 <= a_2 <= ...`, let `S_n = a_1 + ... + a_n`, let `P_n` be the set of sums of distinct terms among `a_1, ..., a_n`, a subset of `[0, S_n]` symmetric under `x -> S_n - x`, and let `T_n = 1 + max{x <= S_n/2 : x not in P_n}`.

From here on `D = {3, 4, 7}`, where `sigma = 1/2 + 1/3 + 1/6 = 1` and `C_k = (3^(k+1) + 2 * 4^k + 7^k)/6`, an integer: `4, 18, 92, 526` at `k = 1..4`. Powers of `3`, `4` and `7` with positive exponents are pairwise distinct, so `M_k` has no repeated term.

**Lemma 3.1 (the interval step).** If `P_n` contains every integer of `[T, S_n - T]` and `a_(m+1) <= S_m - 2T + 1` for every `m >= n`, then every integer `>= T` is a sum of distinct terms of `M_k(D)`. Rows: [Erdos](../claims/erdos.md), rows 7 and 48, whose proofs rest on it.

**Proof.** If `P_m` contains `[T, S_m - T]`, then `P_(m+1) = P_m U (P_m + a_(m+1))` contains `[T, S_m - T] U [T + a_(m+1), S_(m+1) - T]`, one interval when `T + a_(m+1) <= S_m - T + 1`. By induction `P_m` contains `[T, S_m - T]` for every `m >= n`, and `S_m` grows without bound. □

**Lemma 3.2 (the deficit at sigma one).** Let `k >= 1`, `X = a_(m+1)`, `d(X)` the base of which `X` is a power, and for each `d` in `D` let `d^(J_d)` be the least power `d^j >= X` with `j >= k`. Then

```
S_m - X = sum_(d in D, d != d(X)) (d^(J_d) - X)/(d - 1) - C_k ,
```

and both terms of the sum are positive. Row: [Erdos](../claims/erdos.md), row 48.

**Proof.** The terms are distinct, so `a_1, ..., a_m` are exactly the powers below `X`, which for each base are `d^j`, `k <= j < J_d`, summing to `(d^(J_d) - d^k)/(d - 1)`. So `S_m = sum_d d^(J_d)/(d - 1) - C_k`, while `X = sum_d X/(d - 1)` because `sigma = 1`. Subtracting, the term of `d(X)` vanishes since `d(X)^(J_(d(X))) = X`, and for the other two bases `d^(J_d) > X`, a power of another base. □

The lemma is the exact form, at `sigma = 1`, of the surplus bound `S_m - a_(m+1) >= (sigma - 1) a_(m+1) - C_k` of the per-part computation of Bergelson and Simmons (2017, Section 2.7) and Fan (2026, Section 7) (row 7), which at `sigma > 1` closes the certificate once `a_(m+1)` is large and at `sigma = 1` gives only `S_m - a_(m+1) >= -C_k`. The positive sum measures how far the next powers of the two other bases lie above `X`, so a step can fail at a large term only where a power of `3` and a power of `4` nearly meet. That is excluded by the one external input, which Section 4 carries to every base set with `sigma = 1` and two bases with no prime factor other than `2` and `3`.

**Theorem 3.3 (Ellison 1971, Theorem 3).** For all positive integers `x, y` with `x` outside `S = {1, ..., 11, 13, 14, 16, 19, 27}`, `|2^x - 3^y| > 2^x e^(-x/10)`. Source: Ellison (1971), page 12-05, read at source, [refs](../refs.md), row Ellison 1971; its proof bounds every solution of `0 < |x log 2 - y log 3| < e^(-x/20)` below `10^160` by the theorem of Baker (1968), and clears `300 <= x <= 10^160` with the continued fraction of `log 2/log 3`.

**Theorem 3.4 (the tight certificate).** Let `D = {3, 4, 7}` and `k >= 1`. Suppose some `n` has `T = T_n <= a_(n+1)`. Put `L = C_k + 2T - 1`, and let `B >= 8` be an integer with `(B + 1)(ln 4 - 1/5) >= ln(3L)`. If `a_(m+1) <= S_m - 2T + 1` for every `m >= n` with `a_(m+1) <= 4^B`, then `M_k(D)` is complete and `F(D, k) = T - 1`. Row: [Erdos](../claims/erdos.md), row 48; witness [Sigma one](../notes/sigma-one.md), section The sigma-one set.

**Proof.** Take `m >= n` with `X = a_(m+1) > 4^B` and suppose the step fails there, `X > S_m - 2T + 1`. Then `S_m - X <= 2T - 2`, so by Lemma 3.2 the sum of the two positive terms is at most `C_k + 2T - 2 < L`, and each is below `L`. Let `3^a` and `4^b` be the least powers `>= X` with exponents `>= k`. If `d(X) = 7`, then `(3^a - X)/2 < L` and `(4^b - X)/3 < L`, so both lie in `(X, X + 3L)`. If `X = 3^a`, then `0 < 4^b - 3^a < 3L`. If `X = 4^b`, then `0 < 3^a - 4^b < 2L`. In every case `0 < |4^b - 3^a| < 3L`, and `4^b >= X > 4^B`, so `b >= B + 1 >= 9`. Then `x = 2b >= 18` is even, so it lies outside `S`, and `y = a >= 1`, so Theorem 3.3 gives

```
|2^(2b) - 3^a| > 2^(2b) e^(-2b/10) = e^(b (ln 4 - 1/5)) >= e^((B + 1)(ln 4 - 1/5)) >= 3L ,
```

a contradiction. So the step `a_(m+1) <= S_m - 2T + 1` holds at every `m >= n`: by hypothesis up to `4^B` and by the contradiction above it. By the definition of `T` and the symmetry of `P_n`, `P_n` contains `[T, S_n - T]`, so Lemma 3.1 makes every integer `>= T` a sum. And `T - 1 < a_(n+1)`, so a sum of distinct terms equal to `T - 1` uses only terms among `a_1, ..., a_n`, and `T - 1` is missing from `P_n`; so `T - 1` is no sum. □

**Theorem 3.5 (exact at sigma one).** `M_k({3, 4, 7})` is complete if and only if the hypotheses of Theorem 3.4 hold at some `n`. So a computation that runs Theorem 3.4 at every `n` closes on every complete level, and a level it leaves open is open only for the computation's cap. Row: [Erdos](../claims/erdos.md), row 48.

**Proof.** One direction is Theorem 3.4. Conversely let `M_k` be complete with largest non-sum `F`, and fix `1 < beta < 2`. By Dirichlet's simultaneous approximation applied to `log 3/log 4` and `log 3/log 7`, there are arbitrarily large exponents `a` with powers `3^a`, `4^b`, `7^c` all within a factor `beta` of one another; let `N` be the least of the three. Then `N` is a term, `N = a_(n+1)` for some `n`, and the least power `>= N` of every base lies in `[N, beta N)`. The terms below `N` sum, base by base, to less than `beta N/(d - 1)`, so `S_n < sigma beta N = beta N < 2 a_(n+1)`. Every `x <= S_n/2` is below `a_(n+1)`, so it is a sum of distinct terms exactly when it lies in `P_n`; so `P_n` and the set of all sums agree on `[0, S_n/2]`. Once `S_n > 2F`, `T_n = F + 1 <= S_n/2 + 1`, and `T_n <= a_(n+1)` since `S_n/2 < a_(n+1)`. From then on `T` and `L` no longer move, nor does `B = max(8, ceil(ln(3L)/(ln 4 - 1/5)) + 1)`, the integer the computation below uses, which meets the condition of Theorem 3.4; and once `N > 4^B` the condition on the terms up to `4^B` is empty. □

The computation runs Lemma 3.1 through the wide certificate of [Problem 124](../notes/problem-124.md), section The surplus certificate (row 26): it keeps `P_n` meet `[0, W]` as `W` bits and the integers of `(W, S_n/2]` missing from `P_n` as a sorted list, which together with the symmetry give all of `P_n`. At each step with `T_n <= a_(n+1)` it sets `L` and `B = max(8, ceil(ln(3L)/(ln 4 - 1/5)) + 1)`, checks the step on every term up to `4^B` in exact integer arithmetic, and stops at the least `n` where the check passes.

**Fact 3.6 (the four levels).** The tight certificate closes for `{3, 4, 7}` at `k = 1, 2, 3, 4` with `B = 8, 16, 19, 23`, and reads `F({3, 4, 7}, k) = 581, 3982888, 166025260, 14961204826`, with `37, 5207, 391070, 23496512` positive non-sums up to `F`. ## Problem 124: the smooth pairs

In this section `D` is a base set with `sigma(D) = 1` and no two bases powers of one integer; Lemma 3.1 and the definitions before it hold for every base set. Two equal powers `d^i = e^j`, `i, j >= 1`, of distinct bases would make `d` and `e` powers of one integer, so `M_k(D)` has no repeated term, and `C_k(D) = sum_(d in D) (d^k - 1)/(d - 1) + sigma(D) = 1 + sum_(d in D) (d^k - 1)/(d - 1)` is an integer. A base is smooth when it has no prime factor other than `2` and `3`, that is when it is `2^alpha 3^beta`. Of the `62` base sets of at most six bases in `[3, 47]` with `sigma = 1`, `gcd = 1` and no two bases powers of one integer, `52` hold two smooth bases, `{3, 4, 7}`, `{3, 4, 10, 19}`, `{3, 5, 6, 21}`, `{3, 6, 7, 13, 21}` and `{3, 4, 13, 19, 37}` among them, and the other `10`, `{3, 5, 7, 13}` among them, hold one (row 65; generator `mixed-powers`, verb `ones 47 6`, which lists all `62`).

**Lemma 4.1 (the deficit at sigma one, any number of bases).** Let `k >= 1`, and let `X = a_(m+1)`, `d(X)` and `d^(J_d)` be as in Lemma 3.2. Then

```
S_m - X = sum_(d in D, d != d(X)) (d^(J_d) - X)/(d - 1) - C_k ,
```

and every term of the sum is positive. If moreover `X > S_m - 2T + 1` for some `T`, then any two bases `e < f` of `D` have powers `e^a, f^b >= X`, `a, b >= k`, with `0 < |e^a - f^b| < (f - 1) L`, where `L = C_k + 2T - 1`. Row: [Erdos](../claims/erdos.md), row 64; witness [Sigma one](../notes/sigma-one.md), section The smooth pairs.

**Proof.** The proof of Lemma 3.2 uses of `{3, 4, 7}` only `sigma = 1` and that no two terms coincide, so it gives the identity. If `X > S_m - 2T + 1`, then `S_m - X <= 2T - 2`, so the sum is at most `C_k + 2T - 2 < L`, and each of its positive terms is below `L`: `X < d^(J_d) < X + (d - 1) L` for every base `d != d(X)`, while `d(X)^(J_(d(X))) = X`. Since `e < f`, the powers `e^(J_e)` and `f^(J_f)` both lie in `[X, X + (f - 1) L)`, and they differ, being terms of distinct bases. □

**Lemma 4.2 (the smooth pair).** Let `e` and `f` be smooth and not powers of one integer, `a, b >= 1`, `u = min(e^a, f^b)`, `rho = 7153/2^19` and `theta = 1 - 1/(10 ln 2)`. Then `|e^a - f^b| >= min(rho u, u^theta)`. Row: [Erdos](../claims/erdos.md), row 64; witness [Sigma one](../notes/sigma-one.md), section The smooth pairs.

**Proof.** Write `e^a/f^b = 2^p 3^q` with integers `p` and `q`, not both `0` since `e^a != f^b`. If `p` and `q` are not of strictly opposite signs, the ratio is at least `2` or at most `1/2`, so `|e^a - f^b| >= u`. Otherwise put `x = |p| >= 1` and `y = |q| >= 1`, and let `g` be the gcd of `e^a` and `f^b`: the two powers are `g 2^x` and `g 3^y` in some order, so `|e^a - f^b| = g |2^x - 3^y|`, and `g 2^x >= u`. If `x` lies outside the set `S` of Theorem 3.3, that theorem gives `|e^a - f^b| > g 2^x e^(-x/10)`, and `2^x <= g 2^x` gives `e^(-x/10) >= (g 2^x)^(-1/(10 ln 2))`, so `|e^a - f^b| > (g 2^x)^theta >= u^theta`. If `x` lies in `S`, then `|2^x - 3^y| >= rho 2^x`, so `|e^a - f^b| >= rho g 2^x >= rho u`: Remark (a) of Ellison (1971), page 12-07, lists the least `|2^x - 3^y|` at each `x` in `S` but `9`, the least ratio to `2^x` falling at `(x, y) = (19, 12)`, where `|2^19 - 3^12| = 7153`; at `x = 9` the least value is `|2^9 - 3^6| = 217`, and `217/2^9 > rho`. The verb `ones 47 6` recomputes the least ratio over all of `S`. □

**Theorem 4.3 (the paired certificate).** Let `D` hold at least two smooth bases, `e < f` the two least, and `k >= 1`. Suppose some `n` has `T = T_n <= a_(n+1)`. Put `L = C_k + 2T - 1` and take an integer `H >= max((f - 1) L/rho, ((f - 1) L)^(1/theta))`. If `a_(m+1) <= S_m - 2T + 1` for every `m >= n` with `a_(m+1) <= H`, then `M_k(D)` is complete and `F(D, k) = T - 1`. Row: [Erdos](../claims/erdos.md), row 64; witness [Sigma one](../notes/sigma-one.md), section The smooth pairs.

**Proof.** Take `m >= n` with `X = a_(m+1) > H` and suppose `X > S_m - 2T + 1`. Lemma 4.1 gives powers `e^a, f^b >= X` with `0 < |e^a - f^b| < (f - 1) L`, and Lemma 4.2, with `u = min(e^a, f^b) >= X > H`, gives `|e^a - f^b| >= min(rho u, u^theta) > min(rho H, H^theta) >= (f - 1) L`, a contradiction. So the step `a_(m+1) <= S_m - 2T + 1` holds at every `m >= n`: by hypothesis up to `H` and by the contradiction above it. The last two sentences of the proof of Theorem 3.4 use nothing of `{3, 4, 7}`, and give the rest. □

For `{3, 4, 7}` the pair is `(3, 4)`, and Theorem 3.4 is the sharper form: there the exponent `x = 2b` of `4^b = 2^(2b)` is even and at least `18`, so outside `S`, and `rho` never enters.

**Theorem 4.4 (exact).** If `D` holds two smooth bases, `M_k(D)` is complete if and only if the hypotheses of Theorem 4.3 hold at some `n`. So a computation that runs Theorem 4.3 at every `n` closes on every complete level, and a level it leaves open is open only for the computation's cap. Row: [Erdos](../claims/erdos.md), row 64.

**Proof.** One direction is Theorem 4.3. The proof of the converse in Theorem 3.5 uses of `{3, 4, 7}` only `sigma = 1` and that no two terms coincide, with Dirichlet's simultaneous approximation applied to `log d_1/log d` for every other base `d`, irrational since no two bases are powers of one integer: it gives arbitrarily large terms `N = a_(n+1)` with `S_n < beta N < 2 a_(n+1)`, at which `T_n = F + 1 <= a_(n+1)` once `S_n > 2F`. From then on `T` and `L` no longer move, nor does the horizon `H` of the computation below, a function of `L`; and once `N > H` the condition on the terms up to `H` is empty. □

The computation runs Theorem 4.3 as Section 3 runs Theorem 3.4, through the same wide certificate: at each step with `T_n <= a_(n+1)` it sets `L` and `H`, the larger of `ceil((f - 1) L 2^19/7153)` in exact integer arithmetic and of `((f - 1) L)^(1/theta)` evaluated in double precision, raised by a relative `10^-9`, rounded up and raised by one, checks the step on every term up to `H` in exact integer arithmetic, and stops at the least `n` where the check passes. The margin, not an interval arithmetic, stands for the rounding in the second term.

**Fact 4.5 (the 52 base sets at five levels).** For each of the `52` base sets above with two smooth bases, the paired certificate closes at `k = 1, 2, 3, 4`, and for each but `{3, 4, 7}` at `k = 5`; so `sum_(d in D) P(d, k)` is cofinite for all `52` at `k <= 4` and for `51` at `k = 5`. `{3, 4, 7}` at `k = 5` caps at `W = 2^35`, and by Theorem 3.5 is open here only for the cap; `{3, 4, 7}` has the largest non-sum of the `52` at each `k <= 4`. For `{3, 4, 10, 19}`, `F = 251, 66091, 4138541, 1052160335, 271729742861` at `k = 1..5`, with `13, 1331, 84085, 6771915, 516280748` positive non-sums up to `F`, and its `H = 186717655760522` at `k = 5` is the largest horizon met. The same values come back at `W = 2^33` on every cell that closes there and at `W = 2^24` on every cell at `k <= 4`; a plain knapsack agrees on `F` and the count of non-sums in all `104` cells at `k = 1, 2`; and a meet in the middle, independent of the bit array, finds `F` the only non-sum in `[F, F + 63]` on seven cells, `{3, 4, 10, 19}` at `k = 1..5` and `{3, 5, 6, 21}` and `{3, 6, 8, 15, 21, 29}` at `k = 5`. Domain: the `52` sets, `k = 1..5`. Row: [Erdos](../claims/erdos.md), row 65; generator `mixed-powers`, verbs `pairs 47 6 5 35 26 2`, `pairs 47 6 5 33 25 3`, `pairs 47 6 4 24 25 4`, `pcontrol 47 6 2`, `split 3,4,10,19 1 251 64`, `split 3,4,10,19 2 66091 64`, `split 3,4,10,19 3 4138541 64`, `split 3,4,10,19 4 1052160335 64` and `split 3,4,10,19 5 271729742861 64`, with the `split` runs at `3,5,6,21` and `3,6,8,15,21,29` at `k = 5` named in the README of `mixed-powers`.

**Fact 4.6 (every base set containing one of the 52).** Every base set containing one of the `52` sets of Fact 4.5 has `M_k` complete at `k = 1, 2, 3, 4`, and every one containing one of the `51` that close at `k = 5` is complete at `k = 5` too, with no bound on its other elements. Domain: `k = 1..5`. Rows: [Erdos](../claims/erdos.md), rows 9 and 65.

**Proof.** As for Fact 3.7: `M_k` of the larger set contains `M_k` of the smaller as a multiset (row 9), and Fact 4.5 applies. □

## Open problems

The value `g_3(8)`. Fact 2.7 gives `g_3(8) <= 3 * 474 = 1422`, and Theorem 1.1 of Korsky (2026) gives a lower bound; nothing between the two is computed here. The search of Section 2 is not run at `n = 8`: the elements triple and the tree gains a level, and it would want a cut at the last two levels as cheap as the bit test it replaces. Whether the extremal sets follow a pattern is open: `n = 6` has two and `n = 7` one (Fact 2.5), and the step `{1} U 3A` is not optimal at `n = 7`, since `3 * 168 = 504 > 474`. The page's question whether `g_3(n) >> 3^n` is answered in the negative by Costa (2026); the order of `g_3(n)/3^n`, which tends to `0`, is open here.

The bases `3, 4, 7` at `k >= 5`. No level `k >= 5` is settled here: at `k = 5` the run caps at `W = 2^35`, the one cell of Fact 4.5 left open. By Theorem 3.5 a run of the tight certificate at level `k` closes after finitely many steps exactly when the level is complete, so a level that never closes is incomplete; Question 2 for `{3, 4, 7}` asks for every `k` at once, and the certificate settles one level per run, as Theorem 4.4 does for every base set of Section 4.

Base sets with `sigma = 1` and one smooth base. The other `10` base sets of the census of Section 4, `{3, 5, 7, 13}` among them, hold one smooth base, so Theorem 4.3 does not reach them. Lemma 4.1 still puts the next powers of any two bases close above every term where the step fails, so the certificate closes the same way given an explicit lower bound on `|d^a - e^b|` for one pair of bases. Ellison's Theorem 3 bounds `|2^x - 3^y|`, and so can serve any pair of bases with no prime factor other than `2` and `3` (Lemma 4.2); a pair with another prime factor wants an explicit lower bound for a linear form in two logarithms, and none is read here. Past the census, every base set with `sigma = 1`, no two bases powers of one integer and two smooth bases is one finite run per level by Theorem 4.4, run here only on at most six bases in `[3, 47]` and at `k <= 5`.

Question 2 in general. It is open. For `1 < sigma(D) < 2` the surplus certificate is exact at each level (rows 7 and 8), and at `sigma(D) = 1` so is the paired certificate when `D` holds two smooth bases (Theorem 4.4), so single levels are finite computations there too, while no theorem read here reaches any base set with `sigma(D) < 2` at every level.
