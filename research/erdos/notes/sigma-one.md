The multiset `M_k(D)`, `sigma`, `C_k`, the sums `P_n`, `T_n`, the step `a_(m+1) <= S_m - 2T + 1`, the interval step, the surplus certificate, the gap proof, the monotone lemma and the wide certificate are those of [Problem 124](problem-124.md), sections The surplus certificate and The deepest hole.

## The sigma-one set

- `{3, 4, 7}` is the one base set in `[3, 12]` with `sigma = 1` and `gcd = 1`. Here `C_k = (3^(k+1) + 2 4^k + 7^k)/6`, an integer: `4, 18, 92, 526` at `k = 1..4`. The surplus lemma gives only `S_m - a_(m+1) >= -C_k`, so the surplus certificate never closes; an exact deficit and one bound on `abs(3^a - 4^b)` close it level by level.
- **Proved (the deficit at sigma one).** Let `D = {3, 4, 7}`, `k >= 1`, `X = a_(m+1)` with base `d(X)`, and `d^(J_d)` the least power `d^j >= X` with `j >= k`. Then `S_m - X = sum_(d != d(X)) (d^(J_d) - X)/(d - 1) - C_k`, and both terms of the sum are positive. Proof: powers of `3`, `4` and `7` with positive exponents are pairwise distinct, so `S_m` is the sum of the powers below `X`, which is `(d^(J_d) - d^k)/(d - 1)` per base; `X = sum_d X/(d - 1)` since `sigma = 1`; and `d^(J_d) = X` exactly at `d = d(X)`.
- [Ellison 1971](https://www.numdam.org/item/STNB_1970-1971____A10_0/), read at source, Theorem 3 on page 12-05: `abs(2^x - 3^y) > 2^x e^(-x/10)` for all positive integers `x, y` with `x` outside `S = {1, ..., 11, 13, 14, 16, 19, 27}`. His proof bounds every solution of `0 < abs(x log 2 - y log 3) < e^(-x/20)` below `10^160` by Baker's 1968 theorem, then clears `300 <= x <= 10^160` with the continued fraction of `log 2/log 3`.
- **Proved (the tight certificate).** Let `D = {3, 4, 7}` and `k >= 1`. Suppose some `n` has `T = T_n <= a_(n+1)`. Put `L = C_k + 2T - 1`, and let `B >= 8` be an integer with `(B + 1)(ln 4 - 1/5) >= ln(3L)`. If `a_(m+1) <= S_m - 2T + 1` for every `m >= n` with `a_(m+1) <= 4^B`, then `M_k(D)` is complete and `F(D, k) = T - 1`.
- Proof: take `m >= n` with `X = a_(m+1) > 4^B` and suppose the step fails there. Then `S_m - X <= 2T - 2`, so the sum in the deficit lemma is below `L`, and each of its two positive terms is below `L`. Let `3^a` and `4^b` be the least powers `>= X` with exponents `>= k`. If `d(X) = 7`, both lie in `(X, X + 3L)`. If `X = 3^a`, then `0 < 4^b - 3^a < 3L`. If `X = 4^b`, then `0 < 3^a - 4^b < 2L`. In every case `0 < abs(4^b - 3^a) < 3L` and `4^b >= X > 4^B`, so `b >= B + 1 >= 9`. Then `x = 2b >= 18` is even and outside `S`, and Ellison gives `abs(2^(2b) - 3^a) > 2^(2b) e^(-b/5) = e^(b (ln 4 - 1/5)) >= 3L`, a contradiction. So the step holds at every `m >= n`. `P_n` contains `[T, S_n - T]` by the definition of `T` and symmetry, so the interval step makes every integer `>= T` a sum. `T - 1 < a_(n+1)` is missing from `P_n`, so it is no sum.
- **Proved (exact at sigma one).** `M_k({3, 4, 7})` is complete if and only if the tight certificate exists at some `n`, so a level the run leaves open is open only for the cap. Proof: as in the gap proof, with `sigma beta = beta < 2`, there are arbitrarily large terms `N = a_(n+1)` with `S_n < beta N < 2 a_(n+1)`, where `P_n` and `FS(M_k(D))` agree on `[0, S_n/2]`; once `S_n > 2F`, `T_n = F + 1 <= a_(n+1)`, so `L` and `B` stop moving, and once `N > 4^B` the finite clause is empty.
- **Verified** (verb `tight 4 31`, `0.4` s): the tight certificate closes at `k = 1, 2, 3, 4`. `F({3, 4, 7}, k)` reads `581, 3982888, 166025260, 14961204826`, with `37, 5207, 391070, 23496512` positive non-sums up to `F`. It closes at `a_n = 3^7, 3^15, 4^15, 4^18`, with `B = 8, 16, 19, 23`; the step holds on every term from `a_(n+1)` up to `4^B`, the least slack `S_m - 2T + 1 - a_(m+1)` being `553, 2299181, 848028876, 30780137790`; and `(B + 1)(ln 4 - 1/5) - ln(3L)` is at least `2.516`. The value `581` at `k = 1` is the one Burr, Erdos, Graham and Li state; `k = 2, 3, 4` appear in no source read here, the site's "proved it for `{3, 4, 7}`" reading their single level `s = 1` as the whole question. Controls: `tight 4 20` returns the same cells at `W = 2^20`; a plain knapsack returns `F` at `k = 1, 2` (verb `set`, and a crate test that also matches the count of non-sums); a meet in the middle finds `F` the only non-sum in `[F, F + 63]` at `k = 3, 4` (verb `split`).
- By the monotone lemma, every base set containing `{3, 4, 7}` is complete at `k <= 4`, with no bound on its other elements.
- At `k = 5` the wide certificate stops: at `W = 2^34` with a list of `2^26` middle holes it caps at term `40`, with `S_39 = 86126246796` and `46583206` middle holes already listed (verb `tight 5 34 26`, `12` s, `4.9` GB). By exactness the level is open here only for the cap.

## The smooth pairs

- A base is smooth when it is `2^alpha 3^beta`. Of the `62` base sets of at most `6` bases in `[3, 47]` with `sigma = 1`, `gcd = 1` and no two bases powers of one integer, `52` hold two smooth bases, `{3, 4, 7}`, `{3, 4, 10, 19}`, `{3, 5, 6, 21}` and `{3, 4, 13, 19, 37}` among them; the other `10`, from `{3, 5, 7, 13}`, hold one (verb `ones 47 6`, which lists all `62`).
- **Proved (the deficit at sigma one, any number of bases).** Let `sigma(D) = 1`, no two bases powers of one integer, and `k >= 1`. Then `C_k = 1 + sum_d (d^k - 1)/(d - 1)` is an integer, and with `X`, `d(X)` and `J_d` as above, `S_m - X = sum_(d != d(X)) (d^(J_d) - X)/(d - 1) - C_k` with every term positive. Proof: the proof for `{3, 4, 7}` uses only `sigma = 1` and that no two terms coincide; and `C_k = sum_d (d^k - 1)/(d - 1) + sigma`. So where the step fails, `S_m - X <= 2T - 2`, each term is below `L = C_k + 2T - 1`, and any two bases `e < f` have powers `e^a, f^b >= X` with `0 < abs(e^a - f^b) < (f - 1) L`: one pair of bases closes it.
- **Proved (the smooth pair).** Let `e, f` be smooth and not powers of one integer, `a, b >= 1`, `m = min(e^a, f^b)`, `theta = 1 - 1/(10 ln 2)` and `rho = 7153/2^19`. Then `abs(e^a - f^b) >= min(rho m, m^theta)`. Proof: `e^a/f^b = 2^p 3^q` with `(p, q) != (0, 0)`. If `p` and `q` are not of strictly opposite signs, one power is at least twice the other, and the gap is at least `m`. Otherwise put `x = abs(p)`, `y = abs(q)`: the two powers are `g 2^x` and `g 3^y`, `g` their gcd, so the gap is `g abs(2^x - 3^y)`, and `U = g 2^x >= m`. For `x` outside `S`, Ellison's Theorem 3 makes the gap exceed `U e^(-x/10) >= U^theta`, since `2^x <= U`. For `x` in `S`, `abs(2^x - 3^y) >= rho 2^x`, the least ratio over `S` falling at `(x, y) = (19, 12)` as Ellison's Remark (a) states and verb `ones` recomputes over all of `S`, so the gap is at least `rho U`.
- **Proved (the paired certificate).** Let `sigma(D) = 1`, no two bases powers of one integer, `e < f` the two least smooth bases of `D`, and `k >= 1`. Suppose some `n` has `T = T_n <= a_(n+1)`; put `L = C_k + 2T - 1` and take an integer `H >= max((f - 1) L/rho, ((f - 1) L)^(1/theta))`. If `a_(m+1) <= S_m - 2T + 1` for every `m >= n` with `a_(m+1) <= H`, then `M_k(D)` is complete and `F(D, k) = T - 1`. Proof: a failing step at `X = a_(m+1) > H` gives `(f - 1) L > abs(e^a - f^b) >= min(rho m, m^theta)` with `m >= X > H`, against the choice of `H`; the rest is the proof of the tight certificate, which is the case `D = {3, 4, 7}` with `4^B` in place of `H`.
- **Proved (exact).** For such `D`, `M_k(D)` is complete if and only if the paired certificate exists at some `n`: the proof of exactness at sigma one uses only `sigma = 1` and the Dirichlet scales. So every level of each of the `52` sets is one finite run that halts exactly when the level is complete, on Ellison's Theorem 3 alone. The `10` others take a linear form in two logarithms, in The two-log pairs.
- **Verified** (verb `pairs 47 6 5 35 26 2`, `89.2` s on `2` threads, `7.9` GB): the paired certificate closes all `52` sets at `k = 1, 2, 3, 4` and all but `{3, 4, 7}` at `k = 5`, where `{3, 4, 7}` caps at term `40` at `W = 2^35` as at `2^34`; `{3, 4, 7}` has the largest `F` and `H` at each `k <= 4`, and `{3, 4, 10, 19}` among the `51` at `k = 5`. `F({3, 4, 10, 19}, k) = 251, 66091, 4138541, 1052160335, 271729742861` at `k = 1..5`, with `13, 1331, 84085, 6771915, 516280748` positive non-sums up to `F`, and `H = 186717655760522` at `k = 5`, the largest horizon met, far inside the exact range. Controls: at `W = 2^33` the `48` cells that close at `k = 5` and every cell at `k <= 4` return the same values (`pairs 47 6 5 33 25 3`), and at `W = 2^24` every cell at `k <= 4` (`pairs 47 6 4 24 25 4`); a plain knapsack to `4 F + 4` agrees on `F` and the count in all `104` cells at `k = 1, 2` (`pcontrol 47 6 2`); a meet in the middle finds `F` the only non-sum in `[F, F + 63]` at `{3, 4, 10, 19}`, `k = 1..5`, and at `{3, 5, 6, 21}` and `{3, 6, 8, 15, 21, 29}`, `k = 5` (`split`); a crate test reads the tight certificate's `F`, count, close and slack off the pair rule at `{3, 4, 7}`, `k = 1, 2, 3`.
- By the monotone lemma, every base set containing one of the `52` is complete at `k <= 4`, and one containing one of the `51` at `k <= 5`.

## The two-log pairs

- Ten of the `62` sets hold at most one smooth base, so Ellison's bound reaches none of their pairs. Here a pair `e < f` with a prime factor above `3` takes Laurent's lower bound for a linear form in two logarithms, which caps the close powers, and an exact enumeration of the close powers below the cap.
- [Laurent 2008](https://doi.org/10.4064/aa133-4-3), read at source, Corollary 2 on page 328 with `m = 10`, `C_2(10) = 25.2`: let `alpha_1, alpha_2` be multiplicatively independent, with `alpha_1`, `alpha_2`, `log alpha_1`, `log alpha_2` real and positive, `b_1, b_2` positive integers and `Lambda = b_2 log alpha_2 - b_1 log alpha_1`; let `D = [Q(alpha_1, alpha_2) : Q]/[R(alpha_1, alpha_2) : R]`, `log A_i >= max(h(alpha_i), abs(log alpha_i)/D, 1/D)` and `b' = b_1/(D log A_2) + b_2/(D log A_1)`. Then `log abs(Lambda) >= -25.2 D^4 max(log b' + 0.38, 10/D, 1)^2 log A_1 log A_2`. For integers `alpha_1 = e`, `alpha_2 = f`, both `>= 3`: `D = 1`, `h(e) = ln e >= 1`, so `log A_1 = ln e` and `log A_2 = ln f`, and `e`, `f` are multiplicatively independent exactly when they are not powers of one integer.
- **Proved (the Laurent ceiling).** Let `e < f` be integers `>= 3`, not powers of one integer, and `1 <= G <= 2^80`. If `a, b >= 1` and `0 < abs(e^a - f^b) < G`, then `m = min(e^a, f^b) < G exp(2520 ln e ln f)`, and so `a < (ln(2G) + 2520 ln e ln f)/ln e`.
- Proof: put `M = max(e^a, f^b)`, `c = 25.2 ln e ln f` and `Lambda = b ln f - a ln e`, nonzero. Then `abs(Lambda) = ln(M/m) <= (M - m)/m < G/m`, so Laurent gives `ln m < ln G + c max(ln b' + 0.38, 10)^2` with `b' = a/ln f + b/ln e <= 2 ln M/(ln e ln f)`, since `a ln e` and `b ln f` are at most `ln M`. Suppose `ln m >= ln G + 100 c`. Then `m >= G`, so `M < m + G <= 2m` and `ln m > b' ln e ln f/2 - ln 2`. If `ln b' + 0.38 <= 10`, then `ln m < ln G + 100 c`, a contradiction. Otherwise `b' > e^9.62 > 15000`, and the two bounds on `ln m` give `b'/2 < (ln G + ln 2)/(ln e ln f) + 25.2 (ln b' + 0.38)^2 < 46.6 + 25.2 (ln b' + 0.38)^2`, using `ln e ln f > (ln 3)^2` and `G <= 2^80`; but at `b' = 15000` the left side is `7500` and the right side below `2565`, and for `b' >= 15000` the left side grows faster, as `50.4 (ln b' + 0.38)/b' < 1/2`. So `ln m < ln G + 100 c`, and `e^a <= M < m + G < 2 G exp(100 c)` gives the bound on `a`.
- **Proved (the neighbour pairs).** For `a >= 1` let `f^(b_0)` be the largest power of `f` at most `e^a`, `b_0 >= 0`, and call `(a, b_0)`, when `b_0 >= 1`, and `(a, b_0 + 1)` the neighbour pairs of `a`. If `b >= 1` and `0 < abs(e^a - f^b) < G`, a neighbour pair of `a` has gap at most `abs(e^a - f^b)` and smaller power at least `min(e^a, f^b)`. Proof: if `b <= b_0`, then `f^b <= f^(b_0) <= e^a`, so `(a, b_0)` has the smaller gap and the larger minimum; if `b > b_0`, then `e^a < f^(b_0 + 1) <= f^b`, so `(a, b_0 + 1)` has the smaller gap and the same minimum `e^a`.
- So put `A(e, f) = ceil((81 ln 2 + 2520 ln e ln f)/ln e) + 1` and let `H(e, f, G)` be the largest smaller power over the neighbour pairs with `a <= A(e, f)` and gap below `G`, `0` if none. By the two lemmas, every `a, b >= 1` with `0 < abs(e^a - f^b) < G <= 2^80` has `min(e^a, f^b) <= H(e, f, G)`. Verb `near` lists the neighbour pairs with gap below `2^80` by exact integer arithmetic in `64`-bit limbs, all `a <= A(e, f)`, `A(3, 5) = 4108` and `A(31, 46) = 9666`, the latter in `0.03` s.
- **Verified** (verb `near 3 5 24`, under `0.01` s): `A(3, 5) = 4108`, and `99` neighbour pairs have `abs(3^a - 5^b) < 2^80`, all with `a <= 51`; the largest ratio of smaller power to gap is `36472996377170786403/779906607448354222 < 47`, at `(a, b) = (41, 28)`. So `abs(3^a - 5^b) >= min(2^80, min(3^a, 5^b)/47)` for all `a, b >= 1`, an explicit bound of Ellison's kind for `(3, 5)`; the closest pairs are `abs(3 - 5) = abs(27 - 25) = 2`. The same verb gives `35` for `(3, 7)` and `36` for `(5, 7)` in place of `47`.
- **Proved (the two-log certificate).** Let `sigma(D) = 1`, no two bases powers of one integer, and `k >= 1`. Suppose some `n` has `T = T_n <= a_(n+1)`; put `L = C_k + 2T - 1`, and let `H` be an integer at least `H(e, f, (f - 1) L)` for some pair of bases `e < f` with `(f - 1) L <= 2^80`. If `a_(m+1) <= S_m - 2T + 1` for every `m >= n` with `a_(m+1) <= H`, then `M_k(D)` is complete and `F(D, k) = T - 1`. Proof: a failing step at `X = a_(m+1) > H` gives, by the deficit at sigma one, `e^a, f^b >= X` with `0 < abs(e^a - f^b) < (f - 1) L`, so `X <= min(e^a, f^b) <= H(e, f, (f - 1) L) <= H`, a contradiction; the rest is the proof of the tight certificate.
- **Proved (exact for every sigma-one set).** For every base set `D` with `sigma(D) = 1` and no two bases powers of one integer, and every `k >= 1`, `M_k(D)` is complete if and only if the two-log certificate exists at some `n`, the cap `2^80` lifted. Proof: past `2^80`, the proof of the Laurent ceiling still bounds `ln m`, for `m >= G`, by the largest root of `t = ln G + c max(ln(2 (t + ln 2)/(ln e ln f)) + 0.38, 10)^2`, finite since the right side grows like `(ln t)^2`; with `A(e, f)` replaced by the bound this gives on `a`, `H(e, f, G)` is finite at every `G`; the rest is the proof of exactness at sigma one. No smoothness enters: every level of every such base set is one finite run that halts exactly when the level is complete.
