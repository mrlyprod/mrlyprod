- 2026-10-30 [Proved] A primitive integer line `a u - b v = c` is a ray if and only if `a` and `b` are both odd, and then it carries `(-1)^c/(ab)` of the pair term. Take `a, b >= 1` with `gcd(a, b, c) = 1` (the other tilt is `v -> -v`, which flips the sign because `s(-x) = -s(x)` off the integers) and a point of the line with `u` irrational; the limit over odd layers `n` of `s(nu) s(nv)` there is `(-1)^c/(ab)` for odd `a, b` and exactly 0 otherwise, and off every rational line it is 0, since there `1, u, v` are independent over `Q` and `(nu, nv)` equidistributes mod 2 over odd `n`, a ray being a line where it is not 0. Proof: put `d = gcd(a, b)`, `a = d a'`, `b = d b'`, so `gcd(d, c) = 1`. For odd `r` mod `2b` and `n = r + 2bj`, put `y = nu mod 2b`; then `s(nu) s(nv) = s(y) s(a' y/b' - c r/b)`, because moving `y` or `n` by `2b` moves the second argument by an even integer, and along each class `y` equidistributes over `[0, 2b)` since `u` is irrational. Parseval on `s(x) = (4/pi) sum_{k odd} sin(pi k x)/k` makes the mean over `y` a sum over the frequency pairs `(j, k) = t (a', b')`, which are both odd only when `t, a', b'` are odd, of `(8/pi^2) cos(pi t c r/d)/(t^2 a' b')`. The mean of the cosine over odd `r` is 0 for even `d` (then `c` is odd) and, for odd `d`, 0 unless `d | t`, when it is `(-1)^c`; with `t = d t'` the sum is `((-1)^c/(ab)) (8/pi^2) sum_{t' odd} t'^-2 = (-1)^c/(ab)`. Carpet ink is `3/4 + (s(nu) + s(nv))/4 - s(nu) s(nv)/4`, so a ray carries `-(-1)^c/(4ab)` of excess ink, and a crosshair `u = a/b` in lowest terms carries the single wave `(1/4) avg s(nu)`, exactly `(-1)^a/(4b)` for odd `b` and 0 for even `b` as the mean of one period of `2b` layers, since for odd `b` the odd `n` give each residue `na mod 2b` of the parity of `a` once, and for even `b` each odd residue once; this is a factor `b` above the slope-one family `1/(4b^2)` at the same denominator. The slope-one and through-the-origin families of the 2-adic row are the cases `a = b` and `c = 0`. Twenty lines at three generic points and 500000 odd layers read within `3.7e-5` of the prediction on the odd lines and `2.1e-5` on the rest, the carpet excess within `1.7e-5` of `-pair/4`, and the period sum matches 181 of 181 reduced `a/b` with `b <= 24`. Witness: ../lab/rs/hexagon-moire.
- 2026-10-30 [Proved] The four flat variance constants are exact covariance sums. For odd `m, n` with `g = gcd(m, n)`, `E s(mu) = 1/m` and `E s(mu) s(nu) = g^2/(mn)`, and `u, v` independent: the tree layer `(1 + s(mu))/2` has `Cov = (g^2 - 1)/(4mn)`; the void layer `(1 + s(mu) s(mv))/2` has `(g^4 - 1)/(4 m^2 n^2)`; the carpet layer `1 - a(mu) a(mv)` with `a = (1 - s)/2` has `E[a_m a_n]^2 - (E a_m E a_n)^2 = (g^2 - 1)/(16mn) (2(1 - 1/m - 1/n) + (g^2 + 1)/(mn))`; the net layer, the complement of `(1 + s(mu))(1 + s(mv))/4`, has the same with `1/m, 1/n` negated. With `L = (N + 1)/2` odd scales, `L Var_L = (1/L) sum Cov`, and every term past the leading gcd sums is `O(ln^2 N)`, because `sum g^2/(m^2 n) = sum_g g^-1 sum_{a, b coprime} 1/(a^2 b) <= (sum 1/g)(sum 1/a^2)(sum 1/b)`. So `lim L Var_L` is the limit of `S2/(2N)` for the tree, `S4/(2N)` for the void and `S2/(4N) + S4/(8N)` for the carpet and the net, with `S2 = sum g^2/(mn)` and `S4 = sum g^4/(m^2 n^2)` over odd `m, n <= N`; the carpet is half the tree plus a quarter of the void only up to `-(g^2 - 1)(1/m + 1/n)/(8mn)` per pair, so the identity of the variance row is asymptotic and not exact. Exact at `N = 999999`: tree `0.4064818975`, void `0.2768055212`, carpet `0.2724275136`, net `0.2724571445`. Witness: ../lab/rs/hexagon-moire.
- 2026-10-30 [Proved] `lim S2(N)/N = pi^2 ln 2/(7 zeta(3)) = 0.8130217042`. Mobius inversion of `g^2 = sum_{d | g} psi(d)` gives `psi(d)/d^2 = sum_{e | d} mu(e)/e^2`, so `S2 = sum_{k, l odd <= N} F(N/max(k, l))/(kl)` with `F(Y) = sum_{d odd <= Y} psi(d)/d^2 = sum_{e odd} (mu(e)/e^2) #{odd d <= Y : e | d} = 4Y/(7 zeta(3)) + O(1)`, since `sum_{e odd} mu(e)/e^3 = 8/(7 zeta(3))`; hence `S2/N = (4/(7 zeta(3))) T2 + O(ln^2 N/N)` with `T2 = sum_{k, l odd} 1/(kl max(k, l))`. Grouping by `c = max(k, l)` and writing `h_c` for the sum of `1/k` over odd `k <= c`, `T2 = sum_{c odd} (2 h_c - 1/c)/c^2 = 2A - 7 zeta(3)/8` with `A = sum_{c odd} h_c/c^2 = sum_n h_n/n^2 - sum_{n even} h_n/n^2`. The even terms: `h_{2k} = O_k = sum_{j <= k} 1/(2j - 1)` and `sum_k O_k/k^2 = int_0^1 (zeta(2) - Li_2(x^2))/(1 - x^2) dx = -int_0^1 (ln^2(1 + x) - ln^2(1 - x))/x dx = 2 zeta(3) - zeta(3)/4` by parts against `artanh x`, so they sum to `7 zeta(3)/16`. The full sum: `h_n = (H_n + B_n)/2` with `B_n = sum_{k <= n} (-1)^(k+1)/k`, `sum H_n/n^2 = int_0^1 ln^2(1 - x)/x dx = 2 zeta(3)` and `sum B_n/n^2 = zeta(2) ln 2 - int_0^1 Li_2(-x)/(1 + x) dx = pi^2 ln 2/4 - zeta(3)/4` by parts with `Li_2(-1) = -pi^2/12`, so `sum_n h_n/n^2 = 7 zeta(3)/8 + pi^2 ln 2/8`. The integrals are `int_0^1 ln^2(1 - x)/x dx = 2 zeta(3)` termwise and `int_0^1 ln^2(1 + x)/x dx = zeta(3)/4`, from `ln^2(1 + x) + ln^2(1 - x) = (ln^2(1 - x^2) + ln^2((1 + x)/(1 - x)))/2` with `int ln^2(1 - x^2)/x = zeta(3)` and, at `t = (1 - x)/(1 + x)`, `int ln^2((1 + x)/(1 - x))/x = int_0^1 2 ln^2 t/(1 - t^2) dt = 7 zeta(3)/2`. So `A = 7 zeta(3)/16 + pi^2 ln 2/8` and `T2 = pi^2 ln 2/4`. The generator reads `A = 1.3810359531` and `sum_n h_n/n^2 = 1.9069358482` against the closed forms to `1e-11`, `T2 = 1.7102721160` against `pi^2 ln 2/4` to 13 digits, `S2/N = 0.8130215039` at `N = 999999`, and the Jordan grouping against the gcd double sum at `N = 6001` to `2.8e-11`. Witness: ../lab/rs/hexagon-moire.
