Fix a prime `p` and integers `a > b >= 1`. The Kummer set `K_(a,b)` holds the integers `k >= 0` with `p` not dividing `C(ak, bk)`, and `K = K_(3,1)` is the set of `k` with `p` not dividing `C(3k, k)`. Write `A_K(x)` for the number of `1 <= k <= x` in `K`, `M_K(x)` for the sum of `mu(k)` over them and `psi_K(x)` for the sum of `Lambda(k)`. At `(a, b) = (2, 1)` the set is the half interval of [mobius](mobius.md), the digit design on `{0..(p-1)/2}`, whose Mobius bound and prime count that page proves from `p = 94939`. At `(3, 1)` and every prime `p >= 5` the set is no digit design, proved in the first section: the digits of `k` are read by a finite automaton whose state is a carry, and this page carries the half interval's theorem onto `K` through a matrix form of its transfer certificate. Past `(3, 1)` the same is read and not proved: over every `2 <= a <= 6`, `1 <= b < a` and prime `a < p <= 31` the only Kummer set that is a product of its digit sets below `p^3` is `(2, 1)` (**Verified**, verb `family`); at `p <= a` it fails, `K_(3,1)` at `p = 3` being `{0}`, the design on `{0}`. Every number below is printed by [lab/py/kummer-carry](../lab/py/kummer-carry/).

## The carry automaton

- **The automaton. Proved.** Let `p >= 5` and read the digits `d_0, d_1, ..` of `k` from the lowest, starting in state `0`. In state `c` a digit `d` is allowed and moves to state `0` when `3d + c <= p - 1`, is allowed and moves to state `1` when `2d + c >= p` and `3d + c <= 2p - 1`, and is refused otherwise. Then `k` lies in `K` exactly when every digit is allowed. Proof. By [Kummer 1852](https://eudml.org/doc/147500), `v_p(C(m + n, m))` is the number of carries in the addition `m + n` at base `p`, and `C(3k, k) = C(k + 2k, k)`. The doubling `2k` has digit `e_i = 2 d_i + c_i - p c_(i+1)` with `c_0 = 0` and `c_(i+1) = 1` exactly when `2 d_i + c_i >= p`, and `c_i <= 1` since `2(p - 1) + 1 < 2p`; the state is this carry. If no carry of `k + 2k` arrives at position `i`, the column there sums `d_i + e_i = 3 d_i + c_i - p c_(i+1)`, which is at most `p - 1` exactly under the two allowed cases, `3d + c <= p - 1` forcing `2d + c <= p - 1`. Above the top digit `2k` holds the single digit `c_L <= 1` against a zero of `k`, a column sum at most `1`. So `k + 2k` carries nowhere exactly when every digit is allowed. The digit `0` is allowed in both states and moves to state `0`, so leading zeros change nothing and `K` below `p^L` is the set of accepted words of length `L`. □
- **The digit sets. Proved.** Write `D_(c c')` for the digits read in state `c` that move to state `c'`. Solving the inequalities, `D_00 = {0..floor((p-1)/3)}`, `D_01 = {(p+1)/2..floor((2p-1)/3)}`, `D_10 = {0..floor((p-2)/3)}` and `D_11 = {(p-1)/2..floor((2p-2)/3)}`, four intervals. At `p = 1 mod 6` they have `(p+2)/3`, `(p-1)/6`, `(p-1)/3` and `(p+5)/6` digits, `D_10` being `D_00` less its top digit `(p-1)/3` and `D_11` being `D_01` with `(p-1)/2` added; at `p = 5 mod 6` they have `(p+1)/3`, `(p+1)/6`, `(p+1)/3` and `(p+1)/6`, with `D_10 = D_00` and `D_11 = D_01 - 1`. Either way each state keeps exactly `fill = (p+1)/2` digits, and both states keep the consecutive pair `{0, 1}` inside the kernel to state `0`. State `0` keeps the two intervals `F* = D_00 u D_01`, the low third and the slice from a half to two thirds, the row-0 design of the sections below. At `p = 3` state `0` keeps only the digit `0`, so `K = {0}`: `3` divides `C(3k, k)` at every `k >= 1`.
- **A width-2 rule and not a digit design. Proved.** An allowed digit moves to state `1` exactly when it is at least `(p-1)/2`, so the state after a digit is a function of that digit and `K` is the set of `k` whose word, with one `0` placed below the units digit, has every window of two adjacent digits allowed: a width-2 rule of the memory dial on [beneath](beneath.md) at base `p`, read from the units end. It is no product set. Let `u = (p+1)/2`, which moves state `0` to state `1`, and let `v` be a digit allowed in state `0` and refused in state `1`, `v = (p-1)/3` at `p = 1 mod 6` and `v = (2p-1)/3` at `p = 5 mod 6`. Then `u` and `v p` lie in `K` and `u + v p` does not, while a digit design holding `u` and `v p` holds `u + v p`. At `p = 7` that is `4 = 4_7` and `14 = 20_7` in `K` and `18 = 24_7` outside it, the sum `24 + 51` of `18` and `36` carrying at position `1`.
- **The check. Verified.** The automaton against Kummer's carry count `(s_p(k) + s_p(2k) - s_p(3k))/(p - 1)`, `s_p` the digit sum, with `0` mismatches: at every `k < p^5` for `p = 5, 7, 11, 13`; at every `k < 101^3` directly; and at every `k < 101^5 = 10510100501` through `k = 101^2 q + r`, where the digit sums of `k`, `2k` and `3k` split exactly over the carries `floor(2r/101^2)` and `floor(3r/101^2)`, so that the automaton's verdict and the count are compared on all `61` value pairs of the carry classes and so on every `k`. The four intervals, the row sums and the pair hold at every prime `5..2999`, the witness `u, v p, u + v p` at all `428` of them, and `K` holds exactly `((p+1)/2)^5` integers below `p^5` at all five primes, `345025251` at `101` (verb `kummer`, under a second).

## The mass of every Kummer set

- **The automaton of every pair. Proved.** Let `a > b >= 1` and let `p > a` be prime. Since `C(ak, bk) = C(bk + (a-b)k, bk)`, Kummer's theorem makes `K_(a,b)` the set where `bk + (a-b)k` carries nowhere. The state is the pair `(c_1, c_2)` of carries of the multiplications by `b` and by `a - b`, with `c_1 < b` and `c_2 < a - b`. In state `(c_1, c_2)` the digit `d` meets the digits `x = (bd + c_1) mod p` of `bk` and `y = ((a-b)d + c_2) mod p` of `(a-b)k`; it is allowed when `x + y <= p - 1`, and it moves to `(floor((bd + c_1)/p), floor(((a-b)d + c_2)/p))`, again below `(b, a - b)` since `b(p-1) + b - 1 < bp`. Above the top digit `bk` and `(a-b)k` hold the single digits `c_1` and `c_2`, whose sum is at most `a - 2 < p`, so the top never carries, and the digit `0` is allowed in every state and moves to `(0, 0)`. At `(3, 1)`, `c_1 = 0` and this is the automaton of the section above. The sets of `(a, b)` and `(a, a - b)` are one set.
- **Every state keeps `(p+1)/2` digits. Proved.** In state `(c_1, c_2)` put `z = (ad + c_1 + c_2) mod p`. Then `x + y = z mod p` and `0 <= x + y <= 2p - 2`, so `x + y - z` is `0` or `p`, and the digit is refused exactly when it is `p`. As `d` runs over `0..p-1`, each of `x`, `y` and `z` runs over every residue once, since `p` divides none of `b`, `a - b` and `a`. So the refused digits number `(1/p) sum_d (x + y - z) = (p(p-1)/2 + p(p-1)/2 - p(p-1)/2)/p = (p-1)/2`, and every state keeps `fill = (p+1)/2`. □
- **The mass. Proved.** At every `a > b >= 1` and every prime `p > a`, `K_(a,b)` holds exactly `((p+1)/2)^L` integers in `[0, p^L)`, since from every state exactly `fill` digits continue a word; so `A(p^L) = fill^L`, `p^L` itself lying in the set, and `A(x)` grows like `x^(alpha_p)`, `alpha_p = log((p+1)/2)/log p`, the half interval's exponent, at every pair. In the language of [beneath](beneath.md) the count matrix `M(0)`, entry `(c, c')` the number of digits taking `c` to `c'`, the transform matrix of the next section at frequency `0`, has every row summing to `fill`, so its Perron root is `fill` exactly with right Perron vector the all-ones vector, and the set's dimension is `log_p fill`. At `(3, 1)` the count matrix is `[[(p+2)/3, (p-1)/6], [(p-1)/3, (p+5)/6]]` at `p = 1 mod 6`, with second eigenvalue `lambda_2 = 1`, and `[[(p+1)/3, (p+1)/6], [(p+1)/3, (p+1)/6]]` at `p = 5 mod 6`, rank one with `lambda_2 = 0`; in both `M(0) = fill 1 pi + lambda_2 (I - 1 pi)` with left Perron vector `pi = (2/3, 1/3)`, so the words of length `L` ending in state `c` number exactly `fill^L pi_c + lambda_2^L (delta_(0c) - pi_c)`.
- **The pair. Proved.** At every prime `p >= 2a - 1` every state keeps `{0, 1}` inside its kernel to `(0, 0)`: the digit `0` meets `x + y = c_1 + c_2 <= a - 2`, and the digit `1` meets `x = b + c_1 <= 2b - 1` and `y = a - b + c_2 <= 2(a - b) - 1`, both below `p` and so carrying nothing out, with `x + y <= 2a - 2 <= p - 1`. Between `a` and `2a - 1` the pair can leave a state: `(4, 1)` at `p = 5` in state `(0, 1)`, and `(5, 1)` at `p = 7` in state `(0, 2)`.
- **The check. Verified.** The count `((p+1)/2)^L`, read off Legendre's digit sums `v_p(C(ak, bk)) = (s_p(bk) + s_p((a-b)k) - s_p(ak))/(p - 1)` directly, at every `2 <= a <= 7`, `1 <= b < a`, prime `a < p <= 37` and `p^L <= 200000`, with `0` mismatches; at odd `p <= a` it can fail, `(3, 1)` at `p = 3` holding `1` integer below `3^11` against `2048` and `(4, 1)` holding `8997`. The row count `(p+1)/2` at all `73654` states of every `(a, b)` with `a <= 12` and every prime `a < p < 400`, `0` off, and the pair present in every state at `p >= 2a - 1` (verb `family`, 4 seconds).

## The matrix transform

- **The product. Proved.** For real `u` let `M(u)` be the `2 x 2` matrix with entries `M_(c c')(u) = sum_(d in D_(c c')) e(d u)`, `e(x) = exp(2 pi i x)`. Let `K_i^(c)` be the `k < p^i` in `K` whose word of length `i` ends in state `c`, and `hat K_i^(c)(u)` the sum of `e(k u)` over them. The digit `d_j` contributes `e(d_j p^j u)` to the kernel of the move it makes, so `hat K_i^(c)(u) = e_0^T M(u) M(p u) ... M(p^(i-1) u) e_c`, and `hat K_i = hat K_i^(0) + hat K_i^(1)` is the same product against the all-ones vector `1`. Every entry is a Dirichlet kernel, `abs(M_(c c')(u)) = abs(sin(pi n u)/sin(pi u))` with `n = abs(D_(c c'))`. At `(2, 1)` there is one state and the product is the level transform `hat F_i` of [mobius](mobius.md).
- **The row-0 basis. Proved.** With `P = [[1, 0], [1, 1]]` put `N(u) = P^(-1) M(u) P`. Then `N_00 = M_00 + M_01 = hat F*`, the transform of the row-0 design, `N_01 = M_01`, `N_10 = (M_10 + M_11) - (M_00 + M_01)` and `N_11 = M_11 - M_01`; since `P e_0 = 1` and `e_0^T P = e_0^T`, `hat K_i(u) = e_0^T N(u) N(p u) ... N(p^(i-1) u) e_0`, and `hat K_i^(c)` is the same product against `P^(-1) e_0 = (1, -1)` or `P^(-1) e_1 = (0, 1)`. The second row is small. At `p = 1 mod 6`, `N_10(u) = e((p-1) u/2) - e((p-1) u/3)` and `N_11(u) = e((p-1) u/2)`; at `p = 5 mod 6`, `N_10(u) = N_11(u) = e((p-1) u/2) - e((2p-1) u/3)`; in both, `abs(N_10(u)) = 2 abs(sin(pi n_1 u))` with `n_1 = abs(D_01)`, which is `(p-1)/6` or `(p+1)/6`. So the transform of `K` is that of the digit design `F*` corrected through a second row of two-term sums.
- **The transfer inequality. Proved.** For a nonnegative row vector function `psi` of period `1` put `(T psi)(t) = sum_(r < p) psi((t+r)/p) abs(N((t+r)/p))`, `abs` taken entrywise. For a nonnegative column `w` and real `s` let `W_i(s; psi) = sum_(a < p^i) psi(u_a) abs(N(u_a)) abs(N(p u_a)) ... abs(N(p^(i-1) u_a)) w` with `u_a = s + a/p^i`. Peeling the lowest digit, `a = a' + p^(i-1) r` puts `u_a = (t + r)/p` with `t = p s + a'/p^(i-1)`, and `p^j u_a = p^(j-1) t` mod `1` at `j >= 1`, so the higher factors are free of `r` and `W_i(s; psi) = W_(i-1)(p s; T psi)`; by induction `W_i(s; psi) = (T^i psi)(p^i s) w`. The triangle inequality gives `Sigma_i(s) = sum_(a < p^i) abs(hat K_i(s + a/p^i)) <= W_i(s; e_0^T)` with `w = e_0`, and `T` is monotone. So if `psi >= e_0^T` entrywise, `psi_0 <= 1` and `T psi <= lambda psi` everywhere, then `Sigma_i(s) <= lambda^i` at every `i` and every real `s`, and the shifted sums of `hat K_i^(c)` are at most `(psi_0 + psi_1) lambda^i` through `w = (1, 1)`. At `(2, 1)` this is the transfer operator of the half interval; there it is an identity, here the triangle inequality across the two paths through the second row is a loss, read in The true rate.
- **The `l^infinity` input. Proved.** The row of state `c` in `abs(M(u))` sums to at most `fill - 2 + 2 abs(cos(pi u))`: it carries `fill` digits, and its kernel to state `0` holds `0` and `1`, whose two terms sum to `abs(1 + e(u)) = 2 abs(cos(pi u))`. So the max-row-sum norm has `norm(M(u))_inf <= fill - 2 + 2 abs(cos(pi u))` and `abs(hat K_i^(c)(u)) <= prod_(j < i) (fill - 2 + 2 abs(cos(pi p^j u)))`, which is the per-position bound from which Lemma A and its window and perturbed forms on [coprime](coprime.md) proceed for a digit set holding a consecutive pair. The rows all sum to `fill`, so the max-row norm is the Perron-weighted norm, and with the pair in both states it contracts at a good digit in either state, not once per orbit of the automaton.

## The certificate

- **The certificate. Proved.** At every prime `p >= 13` put `L = log(p/2)`, `n_1 = abs(D_01)`, and with the constants `nu^+ = 1.854292`, `H^+ = 5.672774`, `nu_1^+ = 1.287903` and `H_1^+ = 3.861981` of the bullet below, `A* = fill + (p/(2 pi))(2 nu^+ L + H^+) + (3/2)(p - 1) + (1 - 2/pi) p`, `B* = n_1 + (p/(2 pi))(2 nu_1^+ L + H_1^+) + (p - 1)/6 + (1 - 2/pi) p/2`, `C* = 2 csc(pi/(2p))`, `D* = p` at `p = 1 mod 6` and `D* = C*` at `p = 5 mod 6`, `lambda = (A* + D*)/2 + sqrt(((A* - D*)/2)^2 + B* C*)` and `eta = (lambda - A*)/C*`. Then `psi = (1, eta)` has `T psi <= lambda psi`, so `Sigma_i(s) <= lambda^i` at every `i` and every real `s`, the shifted sums of each `hat K_i^(c)` are at most `(1 + eta) lambda^i`, and `K` carries a certificate with `p^(alpha_1) = lambda/fill`. Proof. With `delta_r = (t + r)/p`, `T psi(t) = (G*(t) + eta C(t), G_01(t) + eta D(t))` for the sums over `r < p` of `abs(hat F*(delta_r))`, `abs(M_01(delta_r))`, `abs(N_10(delta_r))` and `abs(N_11(delta_r))`. If they sit under `A*`, `B*`, `C*` and `D*`, then `T psi <= (A* + eta C*, B* + eta D*) = lambda (1, eta)`, the second entry because `eta (lambda - D*) = B*` is the characteristic equation `(lambda - A*)(lambda - D*) = B* C*`. Each sum has period `1` and is even about `t = 1/2`, since `N(-u)` is the conjugate of `N(u)`, so take `t` in `[0, 1/2]`.
  - `C` and `D`. `abs(N_10(delta)) = abs(e(n_1 delta) - 1)`, and `n_1 r` runs over every residue with `r` since `p` does not divide `n_1`, so `C(t) = 2 sum_(s < p) sin(pi (sigma + s)/p)` with `sigma` the fractional part of `n_1 t`, and the geometric sum gives `C(t) = 2 cos(pi (sigma - 1/2)/p)/sin(pi/(2p)) <= C*`. At `p = 1 mod 6`, `abs(N_11) = 1` and `D = p`; at `p = 5 mod 6`, `D = C`.
  - `G*`. The points are the low `delta = z/p` with `z = j + t`, `0 <= j <= J = (p-1)/2`, and the high `delta = 1 - z/p` with `z = j + 1 - t`, `0 <= j <= J - 1`, all with `z <= p/2`. With `F* = {0..n_0 - 1} u {s_1..s_1 + n_1 - 1}`, `n_0 = abs(D_00)` and `s_1 = (p+1)/2`, a point carries `abs(hat F*) = abs(num_z)/(2 sin(pi z/p))` with `num_z = e(n_0 z/p) - 1 + e((s_1 + n_1) z/p) - e(s_1 z/p)`, the high points giving its conjugate. Here `n_0/p = 1/3 + c_0/p`, `(s_1 + n_1)/p = 2/3 + c_2/p` and `s_1/p = 1/2 + 1/(2p)` with `c_0 + c_2 = 1` (`2/3` and `1/3` at `p = 1 mod 6`, `1/3` and `2/3` at `p = 5 mod 6`), so `abs(num_z - num^0(z)) <= 2 pi (c_0 + c_2 + 1/2) z/p = 3 pi z/p` for the period-6 function `num^0(z) = e(z/3) - 1 + e(2z/3) - e(z/2)`; write `a(z) = abs(num^0(z))`. By `csc w <= 1/w + (2/pi)(1 - 2/pi) w` on `(0, pi/2]`, the chord of the convex `csc w - 1/w`, and `abs(num_z) <= 4`, every point with `z >= 1/2` carries at most `(p/(2 pi)) a(z)/z + 3/2 + 4 (1 - 2/pi) z/p`, and the point `z = t` at most `fill`. The `p - 1` points pay `3/2` each, and their `z` sum to `(p^2 - 1)/4`, so the last terms pay at most `(1 - 2/pi) p`. For the main part group the low `j >= 1` by class `rho` in `{1..6}` mod `6` and the high `j` by `rho` in `{0..5}`: `sum_(q >= 0, rho + 6q <= J) 1/(6q + rho + t) <= 1/(rho + t) + (1/6) log((J + t)/(rho + t))` from `1/(6q + y) <= int_(q-1)^q dx/(6x + y)`, every class being nonempty at `p >= 13`, and the same on the high side with `J - t` in place of `J + t`. The numerators `log(J + t)` and `log(J - t)` are at most `L`, and `a(-z) = a(z)` makes the high classes average to the same `nu(t) = (1/6) sum_(rho < 6) a(rho + t)`, so the main part is at most `(p/(2 pi))(2 nu(t) L + H(t))` with `H(t) = sum_(rho = 1..6) a(rho + t) w(rho + t) + sum_(rho = 0..5) a(rho + 1 - t) w(rho + 1 - t)` and `w(z) = 1/z - (log z)/6`. So `G*(t) <= fill + (p/(2 pi))(2 nu(t) L + H(t)) + (3/2)(p - 1) + (1 - 2/pi) p <= A*`.
  - `G_01`. The same with `num_z = e(n_1 z/p) - 1`, `n_1/p = 1/6 - 1/(6p)` or `1/6 + 1/(6p)`, drift `pi z/(3p)` paying `1/6` a point, `abs(num_z) <= 2`, `a_1(z) = abs(e(z/6) - 1)` in place of `a`, giving `nu_1` and `H_1`, and the point `z = t` paying at most `n_1`: `G_01(t) <= n_1 + (p/(2 pi))(2 nu_1(t) L + H_1(t)) + (p - 1)/6 + (1 - 2/pi) p/2 <= B*`. □

Proved.** On a grid of `200001` points of `[0, 1/2]`, `nu`, `H` and `nu_1` peak at `t = 1/2`, reading `1.854280049`, `5.672677439` and `1.287901102`, and `H_1` at `t = 0`, reading `3.861955914`; the Lipschitz constants `3 pi` for `a`, `pi/3` for `a_1`, and `76.89` and `19.89` for `H` and `H_1` term by term, `w` being monotone, bound each maximum by its grid maximum plus half a grid step times the constant, and the printed `nu^+`, `H^+`, `nu_1^+`, `H_1^+` round that up at the sixth decimal (verb `wall`). - **The wall. Proved.** `alpha_1 = log_p(lambda/fill) < 1/5` at every prime `p >= 13567831`. The tail: at every prime `p >= 13`, `lambda/fill <= (2 nu^+/pi) log p + c_inf` with `2 nu^+/pi <= 1.180479` and `c_inf = 4 + 2(1 - 2/pi) + (H^+ - 2 nu^+ log 2)/pi + (8/pi) nu_1^+/nu^+ <= 7.482879`.
