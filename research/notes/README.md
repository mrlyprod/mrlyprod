# Notes

A note is one topic of the tree written as finished mathematics: present tense, no dates and no story, proofs and exact tables, every number naming the code that computes it. Each result carries one of four tags, and its dated line lives in a claims file.

Start with [the core](core.md), which defines a design and its two moves, and [method](method.md), which says how every number is produced and checked. Each row below is a note's title and its lead, one sentence on what it finds.
