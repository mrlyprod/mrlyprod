Rule 90 from one cell draws Pascal's triangle modulo 2, `P(s, n) = [s + n even, C(s, (s + n)/2) odd]`, and [the design ladder](design-ladder.md) shows that a rule linear on its reach, or agreeing with rule 90 on the windows it meets, keeps every column 2-automatic. This chapter takes the five rules that break that criterion, exercise a nonlinearity to round 4094 or later, have an aperiodic column and still read 4 to 5 kernel words: 22, 126, 129, 161 and 182. Each draws, from one cell, an image of Pascal's triangle under a different map, and the image is automatic because Pascal's columns are. The generator is the verb `lemma` of `lab/rs/design-ladder`.

- *Rule 182* draws, from one cell, `a(t, n) = [abs(n) <= t] (1 + P(t + 1, n))`, `P(s, n) = [s + n even, C(s, (s + n)/2) odd]` Pascal's triangle modulo 2. **Proved** by induction on `t`. Inside the cone the window is the complement of a Pascal window, which lies in `{000, 001, 010, 100, 101}`, and rule 182 agrees on the complements `{111, 110, 101, 011, 010}` with rule 165, `1 + l + r`, the Pascal recursion complemented. At the edge `f(100) = 1` makes the new cell, and the cell beside it reads `([t odd], 1, 0)`, where `f(110) = 0` and `f(010) = 1` give `[t even]`, the value of `1 + P(t + 2, t)`. `lemma` prints 0 differing cells for `t <= 4096`. The nonlinearity sits on the frontier of the light cone only: 4084 of the 4097 rounds meet a window no affine rule fits, and the interior windows never do.
- *Rule 22*, one live neighbour, draws for `t >= 1` `a(t, n) = P(t, n)` when `t + n` is even and `[P(t - 1, n) = 1, P(t - 1, n - 2) = P(t - 1, n + 2) = 0]` when it is odd, a block code of one row of Pascal's triangle. **Proved** by induction on `t`: the step from row `t` to `t + 1` concerns seven consecutive cells of one Pascal row; the same closure, on windows of seven cells with a parity tag, lists the 22 windows that occur, the same 22 the rows `<= 4096` show, and on each the rule 22 step of the block code is the block code of the next row, 0 violations. The base `a(1, .) = 111` holds and `lemma` prints 0 differing cells for `t <= 4096`. The exercise is in the bulk: row `2^k - 1`, `k >= 2`, is the blocks `111` around the isolated live cells of row `2^k - 2`, with the windows `000, 001, 011, 111, 110, 100` that no affine `g` fits, since `g(000) = 0`, `g(001) = g(100) = 1` and `g(011) = 0` force `g(111) = 1` while `f(111) = 0`.
- *Rule 126*, not all three equal, is rule 18 on the difference field `d(t, n) = a(t, n) + a(t, n + 1)`: the new cell is `d(t, n - 1) or d(t, n)`, so `d(t + 1, n) = (1 + d(t, n))(d(t, n - 1) + d(t, n + 1))`. **Proved.** From one cell `d` is the rule 18 orbit of the pair `11` at `-1, 0`; `lemma` prints 0 differing cells for `t <= 4096`, and rule 90 fits its interior windows at every round but the 11 rounds `2^k - 2`. Rules 126, 129 and 161 are proved automatic below.

**Rule 126 from one cell is Pascal's triangle written on two cells per entry, rules 129 and 161 draw its complement, and their columns are 2-automatic. Proved.** Take `P(s + 1, n) = P(s, n - 1) + P(s, n + 1)`, `P(s, -n) = P(s, n)` and `P = 0` off the cone. The coordinate map moves a cell outward to the parity of `t`: `rho_t(n) = n` when `t + n` is even and `n + sgn(n)` when odd (`sgn(0) = 1`), and `A_t(n) = P(t, rho_t(n))`. Claim `a(t, n) = A_t(n)`, by induction on `t` from `A_0 = delta_0`. Rule 126 makes `a(t + 1, n) = 1` exactly when `A_t` is not constant on `n - 1, n, n + 1`. If `t + n` is odd, the outer cells read `P(t, n - 1)` and `P(t, n + 1)` and the centre repeats the outer one farther from `0` (all three are `P(t, 1)` at `n = 0`), so the window is not constant exactly when `P(t, n - 1) + P(t, n + 1) = P(t + 1, n) = 1`. If `t + n` is even and `n >= 1`, the window is `(P(t, n), P(t, n), P(t, n + 2))`, not constant exactly when `P(t, n) + P(t, n + 2) = P(t + 1, n + 1) = 1`; `n <= -1` mirrors, and `n = 0` reads `(P(t, 2), P(t, 0), P(t, 2))`. Each case is `A_(t+1)(n)`.

Rule 129 is `1 + f_126`, and `f_126` takes one value on a window and its complement, so `1 + a(t)` solves rule 129 from `t = 1`, where its row is `000` at `-1, 0, 1` and ones elsewhere. Rule 161 differs from 129 only at the window `101`, the window `010` of `a(t)`, which `a(t)` lacks for `t >= 1`: a one at `a(t, n)` comes from `d(t - 1, n - 1) = 1` or `d(t - 1, n) = 1`, which puts a one at `n - 1` or `n + 1`. So 129 and 161 draw one diagram. Lucas enters in the columns: `a(t, n_0) = P(t, n_0) + P(t, n_0 + sgn(n_0))`, two columns of rule 90 on opposite parities of `t`; `C(t, k)` is odd exactly when the binary digits of `k` lie among those of `t`, the identity `Phi(x)^2 = Phi(x^2)` of the linear-rounds theorem at `p = 2`, so each is 2-automatic, and so are their sum and its complement. `lemma` prints 0 differing cells for `t <= 4096` for 126 against `A_t`, 129 against `1 + a` and 161 against 129, 0 isolated ones in the rows of 126, and 0 for the columns `-8..8` against the formula, `t < 2^15`, kernel words from 3 at column `0` to 10 at column `+-8`.
