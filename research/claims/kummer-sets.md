- 2026-10-05 [Proved] At every prime `p >= 5` the integers `k` with `p` not dividing `C(3k, k)` are the words accepted by a two-state carry automaton read from the units digit: in state `c` a digit `d` moves to state `0` when `3d + c <= p - 1`, to state `1` when `2d + c >= p` and `3d + c <= 2p - 1`, and is refused otherwise; the kernels are four intervals, each state keeps `(p+1)/2` digits and the pair `{0, 1}`, the set is a width-2 rule and no digit design. Witness: notes/kummer.md, section The carry automaton.
