# captcha

A prove-you-are-human puzzle pointed back at the human. A grid of little generated pictures fills the board, the prompt names exactly one of them, and you answer by tapping the right cell or typing the name. Each grid comes from a seed, so a puzzle you liked can be posed again exactly.

## Playing

- The prompt names the one picture that belongs to it; every other cell is drawn from the rest of the catalogue.
- Tap a cell to answer by pointing, or type the name to answer in words.
- A right answer scores a point and deals a fresh grid on the spot.
- One wrong answer ends the run.
- The grid runs from 2x2 up to 5x5, and the *skin* dial draws the pictures in rolled colors or in plain ink.
