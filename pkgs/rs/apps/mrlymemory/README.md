# memory

The card-matching game, dealt with a twist: every round holds its pairs plus one decoy card that matches nothing. The deck shows itself face up for a brief look before flipping over, and each shuffle comes from a seed, so a deal you liked can be replayed card for card.

## Playing

- Each round opens with a look phase: all cards sit face up for 16 beats, then hide. Flips wait until then.
- Flip two cards. A match stays up and scores a point; a miss shows both for a moment before hiding them.
- Clearing every pair deals the next round straight away - the score and round count carry on.
- With *sudden* on, a single miss ends the run.
- Rounds run 2 to 8 pairs across 2 to 8 columns, and the card faces can be tiles, emojis or digits.
