# mrlyweb

The Mrly world assembled: every app behind four doors - boot, list, call, read. `boot(loadout)` installs a named selection of apps into a fresh os; on that os, `list` surveys what is running, `call` performs one verb, and `read` renders any route. Every app crate rides inside, so this one dependency carries the whole world.

Around the doors ride the web trimmings: share cards, gpu shader programs, the skin corpus, and a goose.

## Inside

- **registry** builds the catalogue, the loadouts, the shader programs, and the skin corpus.
- **card** paints a route's share card, a hashed life texture behind the title.
- **goose** is a seeded random player that exercises any installed app.
- **shaders** dresses a fragment program in the shared vertex stage.
