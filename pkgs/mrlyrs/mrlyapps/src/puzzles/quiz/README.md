# quiz

A ten-question picture quiz. Each question shows one small generated picture beside a short list of names, and you pick the name that matches. Every right answer moves the run along; one wrong answer ends it, and clearing the whole run wins. The questions come from a seed, so the same seed asks the same quiz.

## Playing

- Each question offers 3 names by default; the *options* dial widens that to anything from 2 to 8.
- Pick the matching name to score a point and draw the next question.
- The counter shows where you stand, question 4 of 10.
- *length* sets the run, from 2 to 32 questions; answer them all for the win.
- *skin* draws the picture in a rolled color or in plain ink.
